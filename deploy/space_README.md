# FlexProof AI

Research prototype for datacentre flexibility simulation, reliability-aware commitment, and recovery planning. The website and the API run together in this Space; API docs are at `/docs`.

Outputs are simulated, not facility or utility certification. Run history is stored on the container disk and resets when the Space restarts. Source: https://github.com/Varshini-arsh/FlexProof-AI
